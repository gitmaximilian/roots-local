# Roots Local

Roots Local is an open-source desktop application for exploring MyHeritage DNA files and creating PDF reports. It is designed to import, analyze, and export data locally on macOS and Windows.

The desktop implementation and installers under development are tracked in [pull request #1](https://github.com/gitmaximilian/roots-local/pull/1).
