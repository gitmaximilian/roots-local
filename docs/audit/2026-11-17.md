## Implementation order

1. GEN-1 through GEN-3. Limit unsupported medical inferences, add a source-backed reference case matrix, and improve conservative local question matching.
2. DATA-1 and LOCAL-1/2. Guard explicit export options and preserve independent offline sessions during an update. Extend the network and storage test to cover preview.
3. UX-1 through UX-3. Fix focus and responsive issues and clarify the visual—not diagnostic—meaning of the results.
4. Compare performance against the preserved build, verify browser and Rust outputs, then deploy and recheck the actual Cloudflare responses. Record before/after evidence and unresolved items in the pull request.

## Evidence boundaries

Known-case tests establish input-to-output behavior on synthetic records. A real assay comparison, clinical sign-off, physical device matrix, and a named LLM parity benchmark each require their own evidence. A generic language model response is not a clinical reference standard. The LLM comparison cases must be scored against independently specified expected conclusions and abstentions, using only synthetic inputs.
