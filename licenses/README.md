# Third-party components

Roots Local is Apache-2.0. The Typst compiler is distributed under Apache-2.0 with a separate upstream notice. The notice also identifies the fonts embedded in the compiler. See [LICENSE](typst-LICENSE) and [NOTICE](typst-NOTICE).

The frontend uses Tauri API, React, Lucide and PDF.js. See their upstream package licenses and the locked versions in the repository. Rust dependencies and their exact versions are listed in Cargo.lock.

The starter catalog contains original summaries and reference variant identifiers and coordinates checked against dbSNP. Scientific papers are linked and are not redistributed. Imported third-party catalogs, PGS weights and reference FASTA files retain their own terms. Their license and origin should travel with the catalog package.
